## Online Customer Sales Case Study
- A personal project using a simulated dataset to practice my SQL and database skills.
- The project analyzes fictional sales data to answer business questions about customers, orders, products, and returns.


## Tools Used
- MySQL/Workbench
- ERD's 
- Query Optimization  
- Indexing


## Key Components
- Analyzing customer purchases  
- Tracking the product performance
- Revenue trend analysis  
- Return rate analysis   
- SQL queries
- Solving real business questions & scenarios  
- ERD modeling


## Project workflow
- Created the relational database schema  
- Created 5 tables  
- Created realistic online sales data  
- Solved SQL business problems  
- Optimized queries 
- Analyzed customer and product insights  


## Business Questions Answered
- Total revenue calculation  
- Completed orders analysis  
- Basic filtering queries
- Top customers by spending  
- Monthly revenue trends  
- Best-selling products  
- Multi-order customer analysis  
- Customer Lifetime Value (CLV)  
- Revenue contribution %  
- Query optimization using indexing  
- Profit margin analysis  
- Return rate analytics


## SQL Techniques Used
- DDL, DML, DQL
- JOINs
- GROUP BY & HAVING  
- Aggregate Functions  
- CTEs
- Subqueries
- Views
